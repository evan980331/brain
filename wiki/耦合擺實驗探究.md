# 耦合擺實驗探究

本專案針對「耦合擺（Coupled Pendulum）」系統進行深入探討，分析兩擺之間的耦合作用、能量轉移現象以及影響系統耦合週期與阻尼係數的變因。本頁面綜合了相關書面報告與決賽簡報之研究成果。

## 研究概述
本研究建立了一個由兩單擺懸掛於單一水平主繩上的耦合系統。觀察到當單擺 A 釋放時，其能量會透過中繩週期性地傳遞給單擺 B，這種現象稱為「拍頻現象」。實驗重點在於探討不同物理參數（主繩張力、擺錘間距、擺錘質量、擺長、初始角度、線材材質）對「耦合週期（$T_c$）」及「阻尼係數（$c$）」的影響。

## 關鍵科學原理
1.  **耦合模態**：系統可拆解為「同相模態」與「反相模態」之疊加，兩者頻率差異導致干涉產生拍頻。
2.  **能量傳遞**：能量往返的時間定義為耦合週期 $T_c$。
3.  **阻尼效應**：擺錘運動受空氣阻力與節點摩擦力影響，能量隨時間呈現指數衰減。
4.  **位移理論**：節點處的水平位移量 $\Delta x$ 與主繩張力、擺錘間距及擺錘質量相關，實驗指出 $\Delta x / \theta$ 與耦合週期 $T_c$ 有關。

## 變因實驗總結

| 影響變因 | 對耦合週期 ($T_c$) 的影響 | 對阻尼係數 ($c$) 的影響 |
| :--- | :--- | :--- |
| **主繩張力** | 正相關 | 無明顯關係 |
| **擺錘間距** | 正相關 | 無相關 |
| **擺錘質量** | 負相關 | 正相關 |
| **擺長** | 正相關 | 負相關 |
| **初始角度** | 無相關 (35°以下) | 正相關 |
| **線材 (釣魚繩 vs 棉繩)** | 釣魚繩 > 棉繩 | 釣魚繩 $\approx$ 棉繩 |

## 研究結論
1.  **耦合關係**：耦合週期 $T_c$ 與 $(\Delta x / \theta)$ 成反比。實驗驗證了 $T_c \propto \frac{|T_L| L}{m |g| (L^2 - d^2)}$ 的趨勢關係。
2.  **衰減特性**：能量隨時間呈現對數形式衰減，且初始角度越大，衰減係數絕對值越大。
3.  **實驗限制**：人為釋放誤差、測量間距誤差、Tracker 分析過程中的共振重疊問題、錐動擺現象等是主要誤差來源。
